# Texas Tech Football

iPhone app for tracking Texas Tech Red Raiders football — schedule, record, rankings, rivalries, news, live score widget, and game alerts.

See [TexasTechFootball/README.md](TexasTechFootball/README.md) for features and setup.

**Installing on your iPhone?** You don't need Xcode on your phone. Have a Developer account but no Mac? → [TexasTechFootball/NO_MAC_SETUP.md](TexasTechFootball/NO_MAC_SETUP.md)
